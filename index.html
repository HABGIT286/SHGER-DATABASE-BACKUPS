BOT MODULES

رفع مصدر

رفع مستند، تجميع صور، أو إدخال رابط. إضافة وصف اختياري ومراجعة قبل النشر.

المصادر المنشورة

نشر الملف/الصورة/الرابط في القناة وإرفاق بطاقة معلومات المصدر.

تسليم المصدر

إرسال المصدر الأصلي للمستخدم عند اختياره من نتائج البحث أو فهرس المكتبة.

فهرس TXT

توليد ملف عناوين للمصادر حسب النوع، مع الوصف والتاريخ والروابط.

إدارة القناة

تغيير قناة النشر من أدوات الإدارة داخل البوت، بشرط صلاحيات البوت المناسبة.

ترحيب واعتذار

وسائط ترحيب ووسائط إيقاف قابلة للتغيير من الإدارة.

إحصائيات

إحصاءات نشر وتنزيلات وملفات ومستخدمين مع تصدير سجلات.

تقارير المساهم

ملف TXT للمساهمين يُنشأ في المستودع عند تفعيل صلاحيات الكتابة.

حفظ البيانات

فهرس library_index.json يُحفظ في GitHub عبر API باستخدام GITHUB_TOKEN الخاص بالـ Workflow.

الإعدادات في GitHub

VARIABLES & SECRETS
Actions Variablesالقيم غير الحساسة
Actions Secretsتوكن البوت والبيانات السرية
GitHub Pagesإعداد نشر الموقع

الأسرار مثل TOKENN وPROXY_URL يجب وضعها في Secrets وليس Variables. إعدادات مثل ID_TELE وDEV_TELE وGROUP_LINK وWELCOME_IMAGE يمكن وضعها في Variables.

قائمة المتغيرات المتوافقة مع بوتك

CONFIG REFERENCE

TOKENN

توكن Telegram Bot — Actions Secret.

JOIN_CHANEL

معرف القناة أو username — إعداد مطلوب لتشغيل البوت.

ID_TELE

معرف مالك البوت — Variable.

DEV_TELE

اسم حساب التواصل — Variable.

GROUP_LINK

رابط القناة المعروض للمستخدمين — Variable.

WELCOME_IMAGE

رابط الوسائط الافتراضية للترحيب — Variable.

PROXY_URL

رابط proxy عند الحاجة — Secret.

GITHUB_TOKEN

Token تلقائي من GitHub Actions لحفظ الفهرس؛ يحتاج Contents write.

WEB_ADMIN_PASSWORD

لا يمكن التحقق منه بأمان في موقع static. يلزم backend موثوق للتحقق دون كشفه للمتصفح.
